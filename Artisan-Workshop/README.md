# J.C.S. Artisan Workshop — Beta 1

## Included

- Guided setup for resource and finished-product containers
- Automatic backpack detection and replacement of crafting tools
- Two-tool tinkering reserve
- Weapon and armor crafting with material selection
- Selectable imbues with exact target values
- Copy supported properties from an existing item
- Named template slots, import/export codes, batch quantities, and previews
- Weight-aware resource staging and return of unused batch resources
- Reimbue Last retries with verification and paced batch transitions
- Finished-product container handling

## Safety behavior

- Non-exceptional crafted items remain in the backpack.
- Salvage is disabled until its shard-specific controls are recorded and tested.
- Reforging and elemental conversion are not part of Beta 1.
- If the finished-product container is inaccessible, completed items remain in the backpack.
- Resource pulling keeps a 20-stone carrying-capacity margin.

## First run

Keep at least one tinkering tool in the backpack. In Setup, target the secure
resource chest and finished-product container. Crafting tools are detected
automatically from the backpack.
