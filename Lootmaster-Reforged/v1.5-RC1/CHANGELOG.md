# Changelog

## v1.5-RC1
- Prepared for public testing.
- Added public-facing credits and compatibility notes.
- Added first-run safety: AUTO remains off until a default bag is selected.
- Added Fast / Balanced / Safe loot-speed profiles with persistence.
- Added automatic pause while `API.Player.IsDead`.
- Added journal detection for no-loot-right corpses.
- Added two-click Starter Rules reset.
- Retained Normal / Color / Hide corpse presentation.
- Retained integrated treasure chest handler.
- Preserved `JCS_Lootmaster_Settings.json` compatibility.

## Development lineage
Public RC1 is based on J.C.S. Legion Lootmaster Reforged v1.4.
Earlier development versions remain separate and are not overwritten.
