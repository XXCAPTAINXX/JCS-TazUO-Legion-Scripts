# J.C.S. Skill Master

**Current public build: Beta 17**

J.C.S. Skill Master is a TazUO Legion skill-training and character-build manager for InsaneUO.

## Highlights

- Trains InsaneUO free skills plus casting, bard, and other easy-repeat skills.
- Per-skill training goals; manual gains count toward completion.
- BUILD dashboard with saved skill/stat goals.
- GO / STOP button attempts to train every automatable skill in the loaded build.
- Skill and stat auto-lock management.
- Power Scroll warnings when a build goal exceeds the character's current skill cap.
- Stat-cap warnings when the build's stat goals exceed the current total stat cap.
- Built-in, saved, and shareable build profiles.
- Smart channel scheduler overlaps compatible actions while avoiding target/gump/crafting conflicts.
- Bard trainers auto-detect replacement instruments as they wear out.
- Peacemaking training uses self-targeted Area Peace.
- Animal Taming switches to Combat Training mastery training at 90+ Taming.
- Guided SETUP / SPOT tooltips explain required targets, tools, resources, and practice locations.

## Included Trainer Areas

- Free skills
- Magery / Necromancy / Chivalry / Spellweaving / Mysticism / Bushido
- Meditation / Spirit Speak / Anatomy / Animal Lore / Evaluating Intelligence / Stealth
- Musicianship / Discordance / Peacemaking / Provocation
- 90+ Animal Taming mastery training
- Resource and crafting trainers including Mining, Lumberjacking, Fishing, Alchemy, and Inscription

Some build skills can currently be tracked but still require manual training. The BUILD dashboard labels those clearly.
