# J.C.S. SuitMaster RC1

J.C.S. SuitMaster RC1 is ready for public testing.

SuitMaster is a Legion/TazUO gear optimizer for InsaneUO. Point it at your equipment storage, choose or create a build profile, and it will scan your gear and build up to **3 complete suit options** based on the stats you care about.

## RC1 includes

- Multiple equipment storage chests
- Built-in and custom build profiles
- Scan My Build to turn your current character into a starting profile
- Inspect Player to copy the visible gearing philosophy of another player
- Flexible +skill-point budgeting
- Up to 3 ranked suit options
- Pull Suit / Return Suit
- Item locking
- Profile sharing/import codes
- Compact Inspect bar for use while playing
- LootMaster Wanted-file integration

This is RC1, so bug reports and weird edge cases are welcome. If **BUILD SUIT** hangs, produces something obviously wrong, or you find a profile/stat issue, please include the build/profile you were using and what happened.
