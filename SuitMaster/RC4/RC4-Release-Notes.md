# J.C.S. SuitMaster RC4

RC4 changes the optimizer so configured minimums are true suit requirements rather than soft scoring preferences.

- If one or more complete suits meet every configured minimum, suits that miss a minimum are excluded from final ranking.
- Candidate pruning preserves strong contributors to required properties such as FC/FCR.
- Priority 0 gives no extra optimization benefit after a configured minimum is satisfied.
- If no possible complete suit satisfies all minimums, SuitMaster shows the closest fallback and reports the remaining deficits.
- Includes the RC3 Lucky Dexer Luck/SSI scoring changes.

Built for TazUO Legion / InsaneUO.
